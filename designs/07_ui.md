# 07 - UI & Frontend

## 1. Mục tiêu

UI phải phản ánh đúng state từ server, dễ dùng trên desktop và mobile, và không làm người chơi mất ngữ cảnh khi hành động.

## 2. Stack

- React + Vite
- Zustand cho UI state
- Socket.IO client cho realtime
- TypeScript cho toàn bộ codebase

## 3. State model

- Game state không đi qua Zustand.
- UI state mới lưu trong store.
- Chat, lobby và auth là phần hợp lý để giữ ở client state.

## 4. Layout

- Board phải rõ trung tâm.
- Sidebar chỉ nên giữ phần phụ trợ.
- Chat chỉ hiện trong online mode.
- Mobile cần phiên bản gọn hơn, tránh ép cuộn quá nhiều.

## 5. Tương tác

- Selection phải reversible.
- Invalid action phải báo rõ.
- Side effect window nên nhỏ và không che toàn màn hình.
- Các control quan trọng cần đặt ở vị trí dễ thấy.
